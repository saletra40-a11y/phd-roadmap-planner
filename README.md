# PhD Roadmap Planner — public demo (Grad-IQ)

Live demo: https://saletra40-a11y.github.io/phd-roadmap-planner/

This is the **demo-only** edition. It runs on sample data, saves nothing, and has no export/import. The full planner (saves in your browser, JSON backup/restore, CSV export, print) is sold separately as a download.

Sections: overview with defense countdown and milestone progress · advisor cold-email checklist, word counter and outreach tracker · milestones (quals, proposal, candidacy, defense) and dissertation chapter tracker · post-PhD job plan (Plan A, industry Plan B, Plan C) with application tracker · defense checklist and graduation regalia (Grad-IQ used regalia: $250–$300 used full set, $125 buyback).

Static HTML/CSS/vanilla JS. Self-hosted fonts. No tracking, no outside requests. Shop link and price live in `config.js` (`BUY_URL`, `PRICE`).

For planning only. Not career, legal, or financial advice.
